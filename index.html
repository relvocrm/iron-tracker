Back up your data

Your data is synchronized with Firebase in real time and also cached locally on this device. Export a JSON backup periodically as an additional recovery copy.

Save it to Google Drive

  1. Tap "Export backup" above — the file downloads to your phone.
  2. Open the Google Drive app, tap the + button, then "Upload".
  3. Select the downloaded file (named like relvoos-backup-2026-08-16.json).
  4. It's now safely stored in your Drive, separate from your phone.
Restore data

Importing a file completely replaces everything currently on this device — old categories, sessions, or entries are wiped first so nothing from before can reappear. Backups from older gym-only versions also import fine — they'll land in your Gym / Fitness area.
